# TG Formatter Bot

Telegram-бот: «сырой» текст о человеке -> фиксированный блок.

```
FIRST NAME: Ms Judith Ann
LAST NAME: DEAKIN
DOB: 18.11.1967
NUMBER DL: DEAKI661187JA9GY 39
ADRESS: 35 Serpentine Road, Kendal, LA9 4PE
```

## Как теперь определяется фамилия (`names.py`)
LLM только извлекает слова; **решение принимает код**, по уликам, не по позиции:
1. **Номер прав DVLA**: первые 5 символов = фамилия, 12–13-й = инициалы имён, месяц >50 = женщина. Самая сильная улика.
2. Явная метка (`Surname:`) или формат `SMITH, John`.
3. Слово КАПСОМ среди обычных; словарь частых личных имён; выбор LLM (слабая улика).
Фамилия — один срез слов, остальное — имя/средние, поэтому она **физически не может попасть в FIRST NAME**.
Если улик мало — бот прямо пишет ⚠️ «проверь фамилию».

## Как проверяется адрес (`address.py`) — полностью бесплатно
1. **postcodes.io** — посткод существует? Опечатки (O/0, I/1…) чинятся.
2. **HM Land Registry (открытые данные)** — реальные адреса (дом, квартира, улица, город, посткод) всех объектов Англии и Уэльса, проданных с 1995 г. Подтверждает дом, исправляет опечатку в улице, находит правильный посткод по «номер + улица + город».
3. **OpenStreetMap** — запасной вариант (Шотландия, Сев. Ирландия, ни разу не продававшиеся дома): проверка улицы, исправление опечаток.
- Статусы: ✅ найден / 🟡 улица реальна, дом не подтверждён / ❌ адреса нет.
- Честное ограничение: это не PAF Royal Mail. «Дом не найден» в бесплатных данных ≠ «дома нет», поэтому бот пишет 🟡, а ❌ ставит только если не существует посткод или улица.
- Платный `IDEAL_POSTCODES_API_KEY` — **необязателен**, просто даёт 100% точность PAF.

## Переменные
`BOT_TOKEN`, `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODELS`, `ALLOWED_USER_IDS`,
`IDEAL_POSTCODES_API_KEY` (рекомендуется), `ADDRESS_TOWN_UPPERCASE=1` (город заглавными).

## Запуск / тесты

pip install -r requirements.txt && python bot.py
